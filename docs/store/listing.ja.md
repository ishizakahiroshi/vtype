# Chrome ウェブストア 掲載文案（日本語）

ダッシュボードの各欄へそのまま貼れる形にしてある。見出しと欄の対応は文末の表を見ること。

## 拡張機能名

vtype

## 短い説明

Web のどのテキスト欄にも声で入力できます。ブラウザ内蔵の音声認識を使うので、登録も回数制限もありません。

## 詳細説明

vtype は、Web ページのテキスト入力欄に声で文字を入れる拡張機能です。画面に見えている入力欄には
うっすらとしたマイクが並び、押して話すと、聞き取れた文字がその欄のカーソル位置へ、話しながら
その場で入っていきます。検索ボックスでも、問い合わせフォームでも、リッチテキストの本文欄でも、
文字を入力できる欄であれば同じように使えます。

認識にはブラウザに組み込まれている音声認識をそのまま使います。そのため API キーもアカウント登録も
不要で、1 日何分までといった利用量の上限もありません。上限を設けて有料版へ誘導する作りに
していないのは、それを持たないこと自体がこの拡張の目的だからです。

マイクの許可は、インストール直後に開くページで一度だけ与えます。認識は拡張機能自身のページで
動くので、訪れたサイトごとに許可ダイアログが出ることはありません。

主な機能:

- 画面上のテキスト欄それぞれに、うっすらとしたマイクが出る（使っている欄だけに絞る設定もある）
- 押して話すと、話しながらその場で欄に文字が入る。カーソルの位置に入り、前後の文字はそのまま残る
- マイクにマウスを置くとパネルが開く。× で欄を空にし、送信でページの送信まで行える
- 録音中は青い波形が動くので、拾えているかがその場で分かる
- 日本語の変換中（IME で変換している間）は書き込みを待つ
- マイクがサイトのボタンと重なるときは、ドラッグしてずらせる。ずらした位置はサイトごとに覚える
- ツールバーのアイコンで、サイトごとに vtype を切れる。切ったサイトの一覧は設定ページで編集できる
- パスワード欄では動かない。読み取り専用の欄と無効化された欄でも動かない

プライバシー:

- 開発者のサーバーへは何も送りません。vtype 自身はどのサーバーへも通信しません
- 個人情報、閲覧履歴、ページの本文、入力内容のいずれも収集しません
- 話した内容の履歴は残しません。欄へ入れたらそれで終わりです
- 認識はブラウザの音声認識に任せます。Chrome ではブラウザが音声を Google の音声認識サービスへ
  送ることで認識が行われます。これは vtype の通信ではなくブラウザの動作です
- 設定（きっかけ・マイクを出す範囲・ずらした位置・除外サイト）はブラウザ内に保存します

使用権限:

- offscreen: 拡張機能自身のページで音声認識を動かすために使います。マイクの許可が一度で済み、
  サイトごとに許可ダイアログが出なくなります
- storage: 設定をブラウザ内に保存するために使います
- すべてのサイトでの実行: テキスト欄はどのサイトにもあるため、どのサイトの欄にもマイクを出せる
  必要があります。ホスト権限（host_permissions）と tabs 権限は要求していません

## カテゴリ候補

仕事効率化（Productivity）

## 言語

日本語 / English

拡張機能自身が両方に対応している（`packages/extension/_locales/` が正本。manifest の名前と説明は
`__MSG_*` 経由で読者の言語に従う）。ダッシュボードの掲載情報も言語ごとに登録でき、日本語はこのファイル、
英語は `listing.en.md` を貼る。言語を足したら、その言語の掲載文もここへ足す。

## スクリーンショット案

1280x800 で 4 枚。**他社のサービスの画面は 1 枚も写さない**（審査で確実に問題になる）。撮影には
自前のデモページか、`packages/extension/testbed/hostile.html` ではなく見栄えのする検証用ページを使う。

1. 検索ボックスのような 1 行の欄に、うっすらとしたマイクが出ているところ
2. マイクにマウスを置いてパネル（× / 送信 / マイク）が開いたところ
3. 録音中。マイクが赤く、青い波形が動き、欄に文字が入りかけているところ
4. 設定ページ（きっかけ・マイクを出す範囲・除外サイトの一覧）
