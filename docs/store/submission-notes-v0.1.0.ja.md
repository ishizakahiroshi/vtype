# Chrome ウェブストア 提出文書（v0.1.0・日本語）

ダッシュボードの「単一用途」「権限の正当化」「データ利用」の各欄へ貼る文面と、審査担当者向けのメモ。
バージョンごとに新しいファイルを作る（前の版を上書きしない）。

## 審査担当者向けメモ

初版です。Web ページのテキスト入力欄へ音声で文字を入れる拡張機能で、認識はブラウザ内蔵の
Web Speech API をそのまま使います。Chrome ではブラウザが音声を Google の音声認識サービスへ送って
認識するので、話した声は Google へ渡ります（掲載情報・プライバシーポリシー・インストール直後の
マイク許可ページの 3 か所で、許可の前に明示しています）。それ以外の通信はなく、開発者のサーバーも
存在しません。

このバージョンで入っているもの:

- 画面上のテキスト入力欄それぞれに、うっすらとしたマイクを表示する（設定で「使っている欄だけ」に絞れる）
- 押して話すと、確定前の文字も含めてその場でカーソル位置へ挿入し、話しながら修正していく
- パネルから欄を空にする / ページを送信する
- 録音中の波形表示
- マイクをドラッグして位置をずらし、サイトごとに記憶する
- ツールバーのアイコンでサイトごとに無効化し、設定ページで一覧を編集する
- 英語と日本語に対応（`_locales/en` と `_locales/ja`。`default_locale` は `en`）。manifest の
  `name` / `description` / `action.default_title` は `__MSG_*` なので、表示は審査担当者の言語に従う
- 診断ログ（**既定は無効**）。設定ページで有効にしたときだけ、録音の時刻・認識のやり直し回数・
  イベント種別・**結果の文字数**・終了理由を `chrome.storage.local` に最大 300 件記録する。
  **認識したテキストは記録しない。** 設定ページから表示・コピー・削除でき、外部へは送信しない

## 単一用途

Web ページのテキスト入力欄へ、音声で文字を入力すること。この 1 つだけを行います。

## 権限に関する説明

- `offscreen`: 音声認識を拡張機能自身の offscreen document で実行するために必要です。ここで動かすことで
  マイクの許可が拡張機能に対して一度だけで済み、利用者が訪れるサイトごとに許可ダイアログが出ることが
  なくなります。content script でマイクを開くと、オリジンごとに許可を求めることになります
- `storage`: 設定（録音を始めるきっかけ、マイクを出す範囲、ドラッグした位置、無効化したサイトの一覧）を
  保存するために必要です。保存先は `chrome.storage.sync` で、無効化したサイトの一覧のみ
  `chrome.storage.local` にも書きます（組織の設定で sync が拒否される環境で、切ったはずのサイトで
  マイクが戻ることを防ぐため）
- content script の `http://*/*` と `https://*/*`（`all_frames`）: テキスト入力欄はあらゆるサイトに
  存在するため、特定のサイトに限定できません。iframe の中の入力欄にもマイクを出す必要があるので
  `all_frames` を使います。**`host_permissions` と `tabs` 権限は要求していません。** そのため拡張機能の
  background はタブがどのサイトを開いているかを知らず、サイトの判定は content script が自分の
  オリジンだけを見て行います
- ページ内容の読み取り: 入力欄の検出と、カーソル位置への挿入にのみ使います。ページ本文の収集や送信は
  行いません
- リモートコードの実行: ありません。すべてのコードがパッケージに含まれています

## データ取り扱い

- 個人情報の収集: なし
- 閲覧履歴・ページ内容の収集: なし
- 入力内容の収集: なし
- 開発者のサーバーへの送信: なし（開発者が管理するサーバーが存在しません）
- 利用状況の計測: なし
- 音声の行き先: vtype は認識を行わず、ブラウザの Web Speech API へ渡します。Chrome の実装では
  ブラウザが音声を Google の音声認識サービスへ送ります。これは vtype の通信ではなくブラウザの動作で、
  vtype はこの経路に宛先を足しません。プライバシーポリシーにも同じ内容を明記しています
- 保存する設定: `trigger` / `micDisplay` / `micOffsets`（オリジンごと・最大 50 件）/
  `excludedSites`（最大 100 件）/ `diagnostics`（診断ログの ON / OFF・既定 OFF）。保存先はブラウザ内
  （`chrome.storage.sync`、および除外リストのみ `chrome.storage.local`）
- 診断ログ: 既定は無効。有効時のみ `chrome.storage.local` に最大 300 件。記録するのは時刻・認識の
  やり直し番号・イベント種別・結果の**文字数**・終了理由で、**認識したテキストは含まない**。
  利用者が設定ページからいつでも削除でき、開発者へは送信されない
- 文字起こしの保存: なし。入力欄へ挿入したら保持しません
- パスワード欄: 対象外です。対象とする入力欄の種類を許可リストで定めており、パスワードは含まれません。
  `autocomplete="current-password"` / `"new-password"` の欄も除外します

## テスト観点

1. 任意のサイトの検索ボックスにマウスを合わせると、欄の右外にうっすらとマイクが出ること
2. マイクを押すと録音が始まり、話した内容がその欄のカーソル位置へ入っていくこと
3. 別オリジンのサイトを 3 つ開いても、マイクの許可ダイアログが 1 度も出ないこと
   （インストール直後に開く許可ページで一度だけ許可します）
4. パスワード欄にはマイクが出ないこと
5. ツールバーのアイコンを押すと、そのサイトでマイクが出なくなること。設定ページ
   （chrome://extensions の詳細 → 拡張機能のオプション）にそのサイトが並ぶこと
6. 設定ページで「使っている欄だけ」に切り替えると、開いたままのページでも再読み込みなしに反映されること
7. 設定ページの「診断ログを取る」が既定でオフであること。オンにして録音すると同じページにログが並び、
   その行に話した内容が一切含まれないこと（文字数だけが出る）
