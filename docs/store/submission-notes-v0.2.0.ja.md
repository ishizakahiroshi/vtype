# Chrome ウェブストア 提出文書（v0.2.0・日本語・下書き）

ダッシュボードの「単一用途」「権限の正当化」「データ利用」の各欄へ貼る文面と、審査担当者向けのメモ。
v0.2.0 の提出時に使う下書き。**v0.1.0 の審査が終わるまでは、ストアの掲載もこの文面も提出しない**。
変わらない欄（単一用途の前半・既存の権限の説明）は v0.1.0 の文書と同じ文を使う。

## 審査担当者向けメモ

v0.1.0 からの変更点:

- 入力モード（通常 / 英語 / カタカナ）と置き換え表。認識した文字をパッケージ内の辞書でカタカナへ変換し、
  利用者が登録した「A を B にする」の組を当てる。どちらもブラウザの中だけで行う
- 任意の権限 `nativeMessaging` によるデスクトップ版との連携（**既定は無効**）。設定ページの
  「デスクトップ連携を有効にする」を押したときだけ権限を求め、許可されなければ何も変わらない。
  連携先は同じパソコンに利用者が入れた vtype のデスクトップ版（Native Messaging のホスト名
  `com.ishizakahiroshi.vtype`）だけで、拡張機能が認識した文字をそこへ渡し、デスクトップ版がブラウザの
  外のアプリへ入力する。デスクトップ版もネットワークへは何も送らない
- 不具合の報告: 設定ページの「報告フォームを開く」は GitHub の新しい issue の入力画面を、版・OS・
  ブラウザ名を埋めて新しいタブで開くだけで、自動では何も送らない

`nativeMessaging` を必須の権限にしていないのは、更新時に既存の利用者の拡張機能が権限の承認待ちで
無効にならないようにするためです。

## 単一用途

Web ページのテキスト入力欄へ、音声で文字を入力すること。利用者がデスクトップ版を入れて連携を
有効にした場合に限り、同じ音声入力の結果を、ブラウザの外のアプリの入力欄へも渡します。

## 権限に関する説明

`offscreen` / `storage` / content script の `http://*/*` と `https://*/*` の説明は v0.1.0 と同じ文を使う。
追加するもの:

- `nativeMessaging`（`optional_permissions`）: 利用者が自分のパソコンに入れた vtype のデスクトップ版へ、
  認識した文字を渡すために使います。設定ページのボタンを押して利用者が許可したときだけ得る任意の権限で、
  既定では持っていません。接続先はホスト名 `com.ishizakahiroshi.vtype` の 1 つだけで、ほかのプログラムとは
  通信しません。デスクトップ版はネットワークへ何も送らず、渡した文字を保存しません
- `storage` の保存項目に、入力モード（`inputMode`）・置き換え表（`replacements`・`chrome.storage.local`）・
  連携の有効 / 無効（`desktopBridge`）を足します。連携の状態は `chrome.storage.session` に置き、
  ブラウザを閉じると消えます

## データ取り扱い

v0.1.0 の内容に次を足す。

- デスクトップ版への受け渡し: 連携を有効にした場合のみ、認識した文字を同じパソコンのデスクトップ版へ
  Native Messaging で渡します。パソコンの外へは出ません。デスクトップ版は文字を前面のアプリへ入力したら
  保持しません
- 置き換え表: 利用者が自分で登録した語の組。ブラウザ内（`chrome.storage.local`）にだけ保存します
- 不具合の報告: ブラウザで GitHub の入力画面を開くだけです。送信は利用者が画面上で行い、拡張機能は
  何も送りません

## テスト観点

v0.1.0 の 1〜7 に加えて:

1. 設定ページの入力モードを「カタカナ」にして話すと、欄に全角カタカナで入ること。モードは
   切り替えたまま残り、ブラウザを再起動しても変わらないこと
2. 置き換え表に 1 行足すと、次に認識した文字から反映されること
3. 権限: インストール直後は `nativeMessaging` を持たないこと（chrome://extensions の詳細で確認）。
   設定ページの「デスクトップ連携を有効にする」を押すと、そのときだけ Chrome が権限を尋ねること。
   断ると連携は無効のままで、ほかの機能は変わらないこと
4. デスクトップ版を入れていない状態で連携を有効にすると、「見つかりません」と案内が出るだけで、
   録音と入力欄への挿入はそのまま使えること
